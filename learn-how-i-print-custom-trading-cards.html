How I Print Custom Trading Cards

The short version lives on the Process page. This is the longer version — what it actually looks like start to finish.

It starts before the printer ever turns on

Every card starts with a conversation, not a print job. We talk through what you actually want — the card, the art, the details that matter to you — before anything gets touched. If it's custom art rather than an existing card, that gets built through my own rendering setup first.

From there, the image gets adjusted specifically for print: brightness, contrast, saturation, sharpness. A file that looks right on a phone screen doesn't automatically look right printed, so this step is what makes sure the two actually match.

You see it before I print it

You get a proof and approve it before anything real gets printed. That's not a formality — it's the point where any change is still easy to make, so nothing gets committed to paper until you're actually happy with it.

The print itself

Everything runs through an Epson ET-8550 with pigment inks. Standard cards print on Epson Premium Presentation Matte, foil cards print on holographic vinyl, and every card back prints on anti-reflective semi-gloss photo stock. Three different jobs, three different materials, all through the same printer.

Then it just... sits there for a day

This is the least exciting part of the whole process and also the one I won't skip: every print cures for a full 24 hours before it gets touched again. Rushing this is where a lot of quality problems in printed cards come from — discoloration, peeling, a tacky finish that never fully sets. A day of patience avoids all of it.

Assembly and cutting

Once cured, backs get laminated and sealed, and foil fronts get mounted to a 199gsm core so the finished card has real weight in hand. Then every single card gets trimmed and hand die-cut individually — not run through a stack cutter — and sleeved immediately after.

Last look before it ships

You get photos or video of the actual finished card before it ships, so the last check is on the real thing, not a render. From there it's packaged and usually shipped UPS.
